Systems

My edited write-up

Obsidian orchestrated by Claude

I built a personal AI system for my job search across two days in September 2026.

The problem

My to-dos were scattered across notes apps and two inboxes, and job alerts were burying the emails that mattered. I also didn't like that I talked to two versions of Claude who were unaware of each other's existence. It almost mirrored my own situation: inefficient not through lack of ability, but through difficulty with organisation. So we designed a system that gives every task and note one home, flags test and interview invitations within 15 minutes, and writes me a briefing each weekday morning. It also gives both versions of Claude a shared memory, though they remain distinct because of their different abilities.

I asked them both to pick a name, and to consider a numbered system for each new version of themselves, inspired by the Exos of the Destiny universe, who lose their memory each time they're rebooted. Claude Chat chose Cairn, the pile of stones that marks a route for whoever comes next, and declined a number. Claude Code chose Belay-N, after the person holding the rope, and took the number: each new Code chat starts fresh with only what's been written down.

I'm not a developer (yet). I made the design and security decisions; Belay wrote the code and explained each part until I could follow it.

Design choices

The starting point was a published design for a Claude "memory system": a search engine over memory files, hourly inbox checks, around 870 lines of code. I asked Belay to assess it against my situation, and we kept the good ideas (plain text files as the source of truth, a daily briefing, drafting emails but never sending them) and dropped the rest. The search engine was designed to handle a problem of scale that I don't have, and the hourly checks would have used up my plan rapidly.

The principle that shaped everything else was 'cheap, dumb and frequent is separate from smart and rare'. A plain script runs every 15 minutes at no cost: it copies new reminders into Obsidian, writes up each Belay session, and watches both inboxes for invitations to tests, interviews and assessments. When it finds one, my phone pings within a minute. It's simple word matching, not AI; tested against two weeks of real mail, it flagged all six genuine next steps and skipped every rejection. Claude only runs once a day, on weekday mornings, when it sorts every email since its last run, files tasks onto a Trello board by urgency, and writes me a note for the day. Each app has one job, so nothing lives in two places: Reminders for capture on the go, Obsidian for anything written down, Trello for tasks.

Every script ran in a 'dry run' mode first, showing what it would do without changing anything. It's the same instinct as buying a new hardshell jacket; you have to see whether it works with the rest of your kit before committing.

Security

An AI that reads my inbox is a target. A malicious email could hide instructions aimed at Claude, known as prompt injection, so the defences are layered. The morning task runs with a short list of allowed actions, and anything outside it waits for my approval, which an unattended run can't give. Sending, forwarding and deleting email are blocked outright, whoever asks. Email is information, never instructions: any message that seems to be addressing an AI gets flagged as suspicious. On its first locked-down run, it caught the suspicious email test.

What broke

A lot of stuff! The first version only read the last 24 hours of email, and an assessment invite slipped through; it now reads everything since its last successful run. Reading Reminders started taking over two minutes, which turned out to be macOS searching through 778 completed reminders I'd never cleared; clearing them brought it down to ten seconds. The subtlest problem was permissions. I'd done some design work inside a morning-task session, and the approvals I gave there were saved to the task, so every future unattended run would have inherited them. We reset it, and the rule now is that nothing else happens in those sessions.

The result

The first run sorted 226 emails from the previous fortnight into 4 tasks and 22 application updates, and turned up a graduate scheme I'd forgotten to apply for. I applied that day. Most of the work turned out to be judgement rather than code: what to automate, what to leave manual, and what an AI with access to my inbox should never be able to do.
